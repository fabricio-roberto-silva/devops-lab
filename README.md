# devops-lab

Hands-on labs for **DevOps practices**: CI/CD pipelines, containers and infrastructure as code.
*Laboratórios práticos de DevOps: pipelines CI/CD, containers e infraestrutura como código.*

## Scope / Escopo
- CI/CD pipelines / Pipelines de CI/CD
- Containers and orchestration basics / Containers e noções de orquestração
- Infrastructure as code / Infraestrutura como código
- Automation and good practices / Automação e boas práticas

```
pipelines/   # CI/CD examples / exemplos de CI/CD
containers/  # Dockerfiles and compose labs / labs de containers
```
